# roblox

Roblox games, prototypes, and portable gameplay systems by Prismtek.

## Architecture rule

Game rules and reusable systems should remain platform-agnostic wherever practical. Roblox-specific services belong behind adapters so the gameplay core can be ported to another engine later without rewriting the entire game.
