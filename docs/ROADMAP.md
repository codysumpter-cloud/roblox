# Roadmap

## Milestone 0 — Studio boot
- Rojo sync into blank Baseplate.
- No runtime errors.
- Normal Roblox avatar spawns.
- Exactly one starter pet follows.
- HUD shows pet + three needs.

## Milestone 1 — Backyard loop
- feed, wash, pet, play;
- gentle needs decay;
- friendship;
- hidden Backyard Egg earned once;
- hatch station consumes one egg and creates one procedural pet;
- selected pet refreshes immediately;
- persistence in a published private test.

## Milestone 2 — Pet controller
- switch from hub avatar to selected pet;
- move/jump;
- grab/carry;
- shove/throw;
- flop/get-up;
- subtle trait modifiers.

## Milestone 3 — King of the Couch
- 2–8 player queue;
- countdown;
- pet-mode transition;
- couch bounds/elimination;
- server-authoritative winner;
- result/replay;
- Party Egg reward;
- return to avatar + companion hub mode.

## Milestone 4 — Big Haul
- cooperative oversized-object physics;
- short obstacle route;
- group completion reward;
- Play Egg reward.

## Later
More hub activities, secrets, fishing/digging, tricks/emotes, breeding using the existing procedural
data model, then trading only after persistence/security hardening.
